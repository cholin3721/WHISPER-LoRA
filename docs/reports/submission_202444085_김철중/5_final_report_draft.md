**저자**: 202444085 김철중
**소속**: 인덕대학교

## 초록 (Abstract)

본 연구는 OpenAI Whisper-large-v3가 한국어 노인 음성에 대해 보이는 성능을 정량적으로 측정하고, PEFT(Parameter-Efficient Fine-Tuning) 기법 중 하나인 LoRA로 도메인 적응을 시도한다. 두 개의 한국어 노인 음성 데이터셋 — AI허브 "자유대화(노인남여)" 샘플과 MINDsLab-ETRI VOTE400 — 에서 zero-shot 베이스라인을 측정한 결과, 데이터셋의 화자 다양성에 따라 CER이 4.25%에서 20.38%까지 5배의 격차를 보였다. 가설로 제시된 외부 VAD(Voice Activity Detection) 재튜닝이 노인 음성의 Deletion 오류를 줄일 것이라는 H2는 데이터로 명확히 반박되었으며 (ΔCER +0.80%p), 그 원인이 노인 발화 특유의 반복(disfluency)을 VAD가 발화 경계로 오인하기 때문임을 정성 분석으로 확인하였다. 반면 H1(LoRA 파인튜닝)은 VOTE400 낭독체에서 학습한 결과 **CER 20.38% → 10.25% (상대 49.7% 감소)**로, PPT 원안의 30% 상대 개선 목표를 초과 달성하였다. 특히 zero-shot에서 가장 어려운 그룹이었던 JN2(전남)는 **34.94% → 12.40% (상대 65% 감소)**로 가장 큰 절대 개선을 보였으며, 이는 LoRA가 어려운 화자 그룹에 우선적으로 적응함을 시사한다. 학습 가능 파라미터는 전체의 0.25%(약 3.9M)에 불과하여 PEFT의 효율성을 정량적으로 입증하였다.

**키워드**: Whisper, LoRA, PEFT, 노인 음성 인식, CER, 도메인 적응, VAD

## 1. 서론 (Introduction)

### 1.1 연구 배경

대한민국은 2025년 65세 이상 인구 비율 20.3%를 돌파하며 초고령 사회 진입을 앞두고 있다 [1]. 고독사 사례가 연 3,924명을 기록하는 등 노인 1인 가구의 사회적 고립이 심화되면서, AI 돌봄 로봇과 음성 기반 케어 서비스에 대한 수요가 빠르게 증가하고 있다. 이러한 서비스의 핵심 기반 기술은 음성 인식(STT, Speech-to-Text)이며, 그 중에서도 OpenAI가 2023년 발표한 Whisper [2]는 68만 시간의 다국어 데이터로 학습된 강력한 베이스라인으로 자리잡았다.

그러나 Whisper를 비롯한 대부분의 STT 모델은 청·장년 화자 데이터에 편향되어 학습되었기 때문에, 다음과 같은 노인 음성 특성에 대해 성능 저하를 보이는 것으로 알려져 있다:

1. **발화 속도 저하** (성인 대비 60~70%)
2. **구음 불명료** (틀니, 발음 변이)
3. **발화 내 장(長)휴지** (2초 이상의 침묵이 문장 종료가 아닌 정상적 호흡)
4. **잡음 동반** (헛기침, 사래)

이러한 특성으로 인해 노인 음성에서의 CER이 일반인 대비 4~5배 높을 것으로 추정되어 왔으나 [3], 한국어 데이터를 사용한 정량적 검증은 부족한 실정이다.

### 1.2 연구 목적 및 가설

본 연구는 두 가지 가설을 통계적으로 검증한다:

- **H1 (주가설)**: Whisper-large-v3에 한국어 노인 음성 데이터(VOTE400)로 LoRA 기반 파인튜닝을 적용하면, baseline 대비 CER이 30% 이상 상대 감소한다.

- **H2 (부가설)**: VAD 임계값을 노인 음성 특성(2초+ 침묵 허용)에 맞춰 재조정하면, Deletion 유형 오류가 추가 감소한다.

본 연구의 학술적 기여는 (1) 한국어 노인 음성에 대한 PEFT 효과의 정량 검증, (2) 두 한국어 노인 음성 데이터셋 (AI허브, VOTE400)의 비교 분석, (3) 가설 반증 가능성을 명시한 엄밀한 실험 설계이다.

## 2. 관련 연구 (Related Work)

### 2.1 Whisper

OpenAI Whisper [2]는 weak supervision 기반으로 68만 시간의 다국어 데이터로 학습된 Transformer 인코더-디코더 모델이다. 30초 단위 mel-spectrogram을 입력으로 받아 텍스트를 출력한다. 한국어는 학습 데이터에 충분히 포함되어 있으나, 노인 음성 특화 fine-tuning 사례는 영어권에 비해 부족하다.

### 2.2 PEFT와 LoRA

LoRA(Low-Rank Adaptation) [4]는 사전학습된 모델의 가중치 W₀를 동결하고, 저랭크 분해된 어댑터 B·A만 학습한다 (W = W₀ + B·A). 전체 모델의 0.5% 미만의 파라미터만 학습되므로 GPU 메모리 절감과 과적합 위험 감소가 가능하다. 본 연구는 Whisper-large-v3 (1.55B params)에 rank=8 LoRA를 적용하여 학습 가능 파라미터를 약 3.9M(0.25%)로 축소하였다.

### 2.3 한국어 노인 음성 데이터셋

- **AI허브 "자유대화(노인남여)"** [5]: 자연스러운 챗봇 대화 시나리오. 60대 이상 화자.
- **MINDsLab-ETRI VOTE400** (Voice Of The Elderly 400hrs) [6]: 65세 이상 화자 100명+, 낭독체 100시간 + 대화체 300시간. IRB 승인 거쳐 구축된 한국어 고령자 전용 코퍼스.

### 2.4 Research Gap

한국어 노인 음성에 대해 Whisper와 PEFT를 결합한 연구는 거의 부재하다. 본 연구는 이 공백을 채우는 첫 시도로 자리매김한다.

## 3. 방법론 (Methodology)

### 3.1 평가 지표

#### 3.1.1 주지표: CER (Character Error Rate)

한국어는 영어와 달리 단어 경계가 모호하기 때문에 단어 단위 WER보다 글자 단위 CER이 더 적합하다.

$$\text{CER} = \frac{S + D + I}{N}$$

- S = 대치(Substitution), D = 삭제(Deletion), I = 삽입(Insertion)
- N = 정답 글자 수

#### 3.1.2 보조 지표

- WER (Word Error Rate): 단어 경계 기반 (한국어에서는 과대평가 경향)
- 오류 유형 분해 (Del/Ins/Sub): 본 연구의 H2 가설 검증에 핵심

### 3.2 실험 설계

#### 3.2.1 Controlled Ablation

네 가지 실험을 진행:

| 실험 | 모델 | 데이터 | 학습 여부 | VAD |
|---|---|---|---|---|
| **E0** | Whisper-large-v3 | AI허브 | 없음 (zero-shot) | 기본 |
| **E2** | Whisper-large-v3 | AI허브 (10초+) | 없음 | 노인용 재튜닝 |
| **E0'** | Whisper-large-v3 | VOTE400 낭독체 (샘플) | 없음 (zero-shot) | 기본 |
| **E1'** | Whisper-large-v3 + LoRA | VOTE400 낭독체 (전체) | **LoRA 학습** | 기본 |

- E0 vs E2: H2 검증
- E0' vs E1': H1 검증 (주가설)

#### 3.2.2 LoRA 학습 설정 (E1')

| 항목 | 값 |
|---|---|
| Base 모델 | `openai/whisper-large-v3` (1.55B params) |
| LoRA 구성 | r=8, alpha=32, target=`q_proj`·`v_proj`, dropout=0.05 |
| 학습 가능 파라미터 | 3,932,160 / 1,547,422,720 (**0.25%**) |
| Train / Val | 95,110 / 16,704 (Val 서브샘플 1,500) |
| Split 전략 | **그룹(region+group) stratified + 화자(pid) disjoint** |
| 배치 크기 | per_device 8 × accum 2 × 2 GPU = 유효 32 |
| Epoch / Step | 2 epoch / 5,946 step |
| Optimizer | AdamW |
| Learning rate | 1e-4 (warmup 50 steps) |
| 정밀도 | fp16 (RTX 8000 Turing 아키텍처라 bf16 불가) |
| 학습 시간 | **6.9시간** (2-GPU DDP) |

#### 3.2.3 디코딩 설정 (전 실험 통일)

- `language="ko"`, `task="transcribe"`
- `num_beams=5` (최종 평가), `num_beams=1` (학습 중 빠른 모니터링)
- `max_new_tokens=128`

### 3.3 데이터 처리

#### 3.3.1 AI허브 라벨 정제

AI허브 transcription의 12% 발화가 `(NO:)`, `(SP:)`, `(FP:)`, `(SN:)` 4종 태그를 포함. 모델 출력과 형식 차이로 인한 measurement artifact를 제거하기 위해 정규식으로 정제:

```python
TAG_RE = re.compile(r'\(([A-Z]+):([^)]*)\)')
def clean_text(t):
    out = TAG_RE.sub(lambda m: ' ' + m.group(2).strip() + ' ', t)
    return re.sub(r'\s+', ' ', out).strip()
```

#### 3.3.2 VOTE400 파일 구조

- 낭독체: `VOTE400_Read/Audio/<REGION><GROUP>/PID_<ID>_<DATE>_<NO>_<REGION>.wav`
- 16개 그룹(지역 5개 × 3~4): DG1~4, GN1~3, GW1~3, JN1~3, SE1~3
- 그룹 간 화자 교집합 = 0 (다른 화자 그룹)
- 그룹의 명시적 의미(정상/장애/연령)는 README에 없음 → CER 기반 데이터 분석으로 어려운 그룹 식별

## 4. 실험 결과 (Results)

### 4.1 E0 — AI허브 베이스라인

**데이터**: AI허브 자유대화(노인남여) 샘플 5명, 2,930 발화, 약 5.3시간.

**라벨 정제 발견**: 12% 비율로 4종 라벨 태그 포함. 정제 후 재측정.

| 지표 | Raw | Cleaned | Δ |
|---|---:|---:|---|
| CER | 6.85% | **4.25%** | -2.60%p |
| Deletion | 4.25% | **0.69%** | -3.56%p |
| Substitution | 1.70% | 1.74% | (불변) |
| Insertion | 0.15% | 0.17% | (불변) |

→ **측정된 Deletion의 85%가 라벨 형식 차이였음**. 모델의 진짜 Deletion 오류는 0.69%로 매우 낮음.

화자간 격차 1.8배 (정제 전 3배에서 축소). 즉 AI허브는 "표준에 가까운 노인" 슬라이스로, H1 검증을 위한 충분한 격차가 부족.

### 4.2 E2 — H2 미니 ablation

**데이터**: AI허브 10초+ 발화 281개.

**결과 — 가설 반박**:

| 조건 | CER | Del% | Sub% | Ins% |
|---|---:|---:|---:|---:|
| A (Baseline) | **6.23%** | **2.37%** | 1.61% | 0.19% |
| B (Elderly VAD) | 7.03% | 3.11% | 1.73% | 0.25% |
| **Δ** | **+0.80%p** | **+0.74%p** | +0.12%p | +0.06%p |

**발화별 추세**: 17개 개선 / 229개 동일 / 35개 악화 (악화가 개선의 2배).

**정성 분석**: VAD가 노인 발화 특유의 반복(disfluency)을 발화 경계로 오인하여 앞부분 절단:

| 정답 | A | B (VAD) |
|---|---|---|
| 그래서 병원 **그래서 병원에** 가서… | 정확 | "그래서 병원에 가서…" |
| 그 방법 중 **그 방법 중에서** 도움을… | 정확 | "그 방법 중에서…" |

**결론**: H2 데이터로 **반박**. Whisper-large-v3 내부 디코더가 이미 발화 내 침묵을 강건하게 처리. 외부 VAD 전처리는 오히려 해롭다.

### 4.3 E0' — VOTE400 zero-shot 베이스라인

**데이터**: VOTE400 낭독체 16개 그룹 × 200개 = 3,200 발화.

| 지표 | 값 |
|---|---:|
| 전체 CER | **20.38%** |
| 전체 WER | 64.63% |
| 정제 후 CER | 21.08% (정제 효과 거의 없음) |

**그룹별 CER**:

### 4.4 E1' — VOTE400 LoRA 파인튜닝 ⭐

**학습**: VOTE400 낭독체 Train 95,110개로 LoRA(r=8) 파인튜닝. 2-GPU DDP, fp16, 2 epoch, 6.9시간.

#### 4.4.3 핵심 발견 — 어려운 그룹이 가장 큰 개선

LoRA 학습 후 그룹 간 균일도가 크게 향상됨. 어려운 화자도 평균 수준으로 끌어올림.

## 5. 논의 (Discussion)

### 5.1 가설 검증의 정직한 cycle

본 연구의 가장 큰 의의는 두 가설을 모두 데이터로 검증했다는 점이다:

| 가설 | 결과 | 의미 |
|---|---|---|
| **H1**: LoRA로 노인 음성 CER 30%+ 감소 | ✅ **지지** (49.7% 달성) | 가설을 정량적 근거로 입증 |
| **H2**: 외부 VAD로 Deletion 감소 | ❌ **반박** (+0.80%p 악화) | 데이터로 가설 폐기 |

H2 반박은 "사후합리화 없는" 정직한 결과이며, 그 반박의 메커니즘 — VAD가 노인 반복 발화를 잘라먹음 — 을 정성 분석으로 확인한 것이 오히려 **H1(모델 내부 적응)의 정당성을 강화**하였다.

### 5.2 PEFT의 효율성 입증

학습 가능 파라미터 비율: **0.25%** (3.9M / 1.55B). 이는:

- VRAM 사용량: 풀 파인튜닝 대비 약 1/10
- 어댑터 저장 크기: **19MB** (풀 모델 ~3GB 대비 0.6%)
- 학습 시간: 6.9시간 (2-GPU DDP)

작은 비용으로 49.7% 상대 개선을 달성한 것은 PEFT 기법의 실용성을 잘 보여준다.

### 5.3 어려운 그룹에서의 큰 개선 — LoRA의 적응 특성

JN2 (zero-shot CER 34.94%, LoRA 후 12.40%)에서 **상대 65% 개선**을 보인 것은 다음과 같이 해석된다:

1. Pretrained Whisper는 표준어 분포에 최적화되어 있어 방언/특수 발화에서 큰 오류 발생
2. LoRA는 학습 데이터의 어려운 부분에 적응 능력을 집중
3. 결과적으로 모델의 "약점"이 더 큰 개선 여지를 제공

이는 LoRA가 **uniform improvement보다 difficulty-targeted improvement**를 한다는 흥미로운 시사점.

### 5.4 데이터셋 선택의 중요성

본 연구에서 가장 중요한 메소드론적 발견은 **데이터셋이 결과를 결정**한다는 점이다:

| 데이터셋 | Zero-shot CER | H1 검증 가능성 |
|---|---:|---|
| AI허브 (cleaned) | 4.25% | ❌ (목표 2.97%, 노이즈 수준) |
| VOTE400 평균 | 20.38% | ✅ (목표 14.3%, 충분한 격차) |
| VOTE400 JN2 | 34.94% | ✅✅ (목표 24.5%, 결과 12.40%) |

만약 AI허브에서만 H1 검증을 시도했다면, 베이스라인이 너무 낮아 30% 상대 개선의 절대값(2.97%)이 측정 노이즈에 묻혀 통계적 유의성을 확보하기 어려웠을 것이다. **VOTE400의 다양성이 H1 검증의 필요조건**이었다.

### 5.5 한계

1. **단일 화자 편향 (E2)**: H2 ablation의 281 발화 중 279개가 단일 화자에서 옴. VOTE400으로 재검증 필요.
2. **paired t-test 미실시**: 본 보고서 작성 시점에 통계적 검정 미완. 추후 추가 예정.
3. **단일 GPU 환경**: 학교 GPU 서버 RTX 8000 × 2로 LoRA 학습 가능하나, 대규모 hyperparameter 탐색은 제한적.
4. **VOTE400 메타데이터 부족**: 화자별 나이/성별/장애 여부 등이 낭독체에는 없어 subgroup 분석 깊이에 한계.
5. **대화체 미사용**: VOTE400 대화체(300시간)는 1 wav = 1 dialog session 구조로 timestamp 분할이 필요해 본 연구에서는 미포함.

## 6. 결론 (Conclusion)

본 연구는 한국어 노인 음성에 대한 Whisper-large-v3의 zero-shot 베이스라인을 두 데이터셋에서 측정하고, 가설 검증을 위한 두 가지 ablation(E2, E1')을 진행하였다.

### 주요 결과

1. **AI허브 베이스라인 CER 4.25%** (라벨 정제 후) — Whisper가 한국어 표준 노인 발화를 이미 잘 인식.
2. **VOTE400 베이스라인 CER 20.38%** — 진짜 노인 인구의 다양성을 마주한 정직한 베이스라인. JN2 그룹에서 34.94%로 outlier 식별.
3. **H2 (외부 VAD 재튜닝) 가설 반박** (ΔCER +0.80%p). Whisper 내부 디코더의 강건성 확인.
4. **H1 (LoRA 파인튜닝) 가설 강력 지지**: VOTE400 CER **20.38% → 10.25% (상대 49.7% 감소)**, PPT 목표 30%를 초과.
5. **JN2 그룹 (가장 어려웠음): 34.94% → 12.40% (상대 65% 감소)** — 어려운 그룹이 가장 큰 절대 개선.
6. **PEFT 효율성**: 학습 가능 파라미터 0.25% (3.9M / 1.55B)로 위 성과 달성. 어댑터 크기 19MB.

### 메소드론적 기여

- 동일한 "노인 음성" 라벨의 두 데이터셋이 데이터 다양성에 따라 zero-shot CER에서 5배 격차를 보일 수 있음을 확인.
- 데이터셋 선택이 가설 검증 가능성을 결정함을 정량적으로 입증.
- 가설 검증의 정직한 사이클 (지지/반박 둘 다) 사례 제공.

### 향후 작업

1. paired t-test + bootstrap CI로 통계적 유의성 명시
2. JN2 정성 분석 — LoRA가 어떤 발음 유형을 개선했는지 규명
3. 전체 11.2만개 풀 inference로 outlier 신뢰도 강화
4. 다른 PEFT 기법(Adapter, IA³, Prefix Tuning)과 비교 ablation
5. 대화체 데이터 활용 (timestamp 분할 + 화자분리 결합)
6. 본 연구자의 선행 연구인 FI-SMOTE [7]를 음성 임베딩 도메인으로 확장하여 화자군 불균형 완화 적용
