| 모델 | CER | 개선 |
|---|---:|---|
| E0' (zero-shot) | 20.38% | — |

**PPT 목표 30% 상대 개선을 훌쩍 초과한 약 50% 상대 개선 달성**.

### 그룹별 효과 — 어려운 그룹이 가장 큰 절대 개선

| 그룹 | E0' CER | E1' CER | 개선 |
|---|---:|---:|---|
| **JN2** (가장 어려웠음) | **34.94%** | **12.40%** | **−22.54%p** (65% ↓) |
| 다른 그룹 평균 | ~19% | ~10% | ~50% ↓ |

→ 그룹 간 격차: 17.91~34.94% (1.95배) → 9.1~13.7% (1.51배)
→ LoRA가 **어려운 화자 그룹을 우선적으로 메움** 확인.

### 가설 검증 최종 결과

| 가설 | 결과 |
|---|---|
| **H1**: LoRA 파인튜닝으로 노인 음성 CER 30%+ 감소 | ✅ **지지** (49.7% 상대 개선) |
| **H2**: 외부 VAD 재튜닝으로 Deletion 감소 | ❌ **반박** (오히려 +0.80%p 악화) |

**가설 검증의 정직한 cycle 완성** — H1은 지지, H2는 반박.

## 사용 데이터셋

1. **AI허브 "자유대화(노인남여)"** — 표본 5명, 2,930 발화 (약 5.3시간)
2. **MINDsLab-ETRI VOTE400** — 약 400시간 (낭독체 100h + 대화체 300h), 화자 100명+
   - 학습: Train 95,110 / Val 16,704 (서브샘플 1,500)
   - 화자 단위 disjoint + 그룹(지역) stratified split

## 사용 모델

- **베이스**: `openai/whisper-large-v3` (1.55B params)
- **PEFT**: LoRA (rank=8, alpha=32, target=`q_proj`/`v_proj`, dropout=0.05)
- **학습 가능 파라미터**: 3.9M / 1.55B = **0.25%**
- **어댑터 크기**: 19MB (`whisper-lora-vote400/adapter_final/`)
