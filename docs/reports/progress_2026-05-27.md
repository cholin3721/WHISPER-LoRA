## 3. 실험 상세

### 3.1 E0 — AI허브 자유대화 zero-shot 베이스라인

**데이터**: AI허브 "자유대화(노인남여)" 샘플 5명, 2,930 발화, 약 5.3시간
**모델**: `openai/whisper-large-v3`, `beam=5, language=ko, max_new_tokens=128`

**핵심 발견 — 라벨 형식 함정**:
AI허브 transcription에 4가지 태그가 12% 발화에 포함됨:

| 태그 | 의미 | 출현 |
|---|---|---:|
| `(SP:content)` | 발음/방언 변이 | 197 |
| `(NO:content)` | 잡음 중첩 발화 | 139 |
| `(FP:content)` | 필러/추임새 | 42 |
| `(SN:content)` | 단발 잡음 | 33 |

Whisper는 깨끗한 본문만 출력 → 단순 비교 시 태그가 다 Deletion 오류로 잡힘.

| 지표 | Raw CER | Cleaned CER | 차이 |
|---|---:|---:|---|
| 전체 | 6.85% | **4.25%** | -2.60%p |
| Deletion | 4.25% | 0.69% | **-3.56%p** |
| Substitution | 1.70% | 1.74% | +0.04%p (그대로) |
| Insertion | 0.15% | 0.17% | +0.03%p (그대로) |

→ **측정된 Deletion 오류의 85%가 모델 실수가 아니라 라벨 형식 차이**

**화자별 cleaned CER** (오름차순):

| 화자 | 성별/나이/지역 | 발화 | CER |
|---|---|---:|---:|
| 1526682663 | F/63/수도권 | 900 | **3.08%** (가장 쉬움) |
| 1520916170 | M/75/수도권 | 490 | 4.16% |
| 1531552733 | F/69/수도권 | 870 | 4.78% |
| 1527825984 | F/71/충청 | 480 | 5.14% |
| 1522434093 | F/60/경상 | 190 | **5.58%** (가장 어려움) |

화자간 격차 1.8배 (정제 전 3배). 즉 대부분의 격차가 라벨 형식 차이에서 옴.

**시사점**: AI허브 베이스라인 4.25%는 너무 낮아서 PPT의 "30% 상대 개선" 목표(2.97%)가 노이즈 수준. **H1 검증의 무대로 부적합**.

### 3.2 E2 — H2 가설 미니 ablation

**가설(H2)**: "VAD 임계값을 노인 음성에 맞게 조정(2초+ 침묵 허용)하면 Deletion 감소"

**실험 설계**:
- 데이터: AI허브 10초+ 발화 281개 (E0에서 Del%가 다른 길이 구간 대비 4~5배 높았던 구간)
- 조건 A: Whisper 기본 (full 오디오)
- 조건 B: Silero VAD 사전분할 (`min_silence_duration_ms=2000`)

**결과**:

| 조건 | CER | Del% | Sub% | Ins% |
|---|---:|---:|---:|---:|
| A: Baseline | **6.23%** | **2.37%** | 1.61% | 0.19% |
| B: Elderly VAD | 7.03% | 3.11% | 1.73% | 0.25% |
| **Δ** | **+0.80%p** | **+0.74%p** | +0.12%p | +0.06%p |

발화별 추세 (Δ>1%p 기준):
- VAD 개선: **17개 (6.0%)** — 대부분 trivial (1글자 차이)
- VAD 동일: **229개 (81.5%)**
- VAD 악화: **35개 (12.5%)** — 의미있는 절단

**원인 (정성 분석)**:
VAD가 노인 발화 특유의 **반복 발화(disfluency)**를 잘라먹음.

| 정답 | A (Baseline) | B (VAD) |
|---|---|---|
| 그래서 병원 **그래서 병원에** 가서… | 정답 그대로 | "그래서 병원에 가서…" (반복 절단) |
| 그 방법 중 **그 방법 중에서** 도움을… | 정답 그대로 | "그 방법 중에서 도움을…" (절단) |
| 그거 휘슬러 **그거 사러** 가서… | 정답 그대로 | "그거 사러…" (앞부분 절단) |

→ **결론**: H2는 데이터로 **반박**. Whisper-large-v3의 내부 디코더가 이미 발화 내 침묵을 강건하게 처리함. **외부 VAD 전처리는 오히려 해롭다**.

**한계**: 281개 중 279개가 단일 화자 `1531552733` (F/69/수도권)에서 옴. 사실상 단일 화자 실험. VOTE400으로 재검증 필요.

### 3.3 E0' — VOTE400 낭독체 zero-shot 베이스라인 ⭐ (오늘 새 산출)

**데이터**: VOTE400 낭독체 16개 그룹에서 각 200개씩 무작위 샘플 = 총 3,200 발화
**모델 설정**: E0와 동일 (`whisper-large-v3, beam=5, language=ko`)

**전체 결과**:

| 지표 | 값 |
|---|---:|
| 발화 수 | 3,200 |
| **전체 CER** | **20.38%** |
| 전체 WER | 64.63% (한국어 단어 경계 모호로 과대평가) |
| 정제 후 CER | 21.08% (구두점 제거 효과 거의 없음) |

**그룹별 CER** (오름차순):

| 그룹 | CER | 비고 |
|---|---:|---|
| SE3 | 17.91% | 가장 쉬움 |
| DG3 | 18.00% | |
| DG2 | 18.15% | |
| SE2 | 18.41% | |
| JN1 | 18.46% | |
| GW3 | 18.49% | |
| DG1 | 18.56% | |
| SE1 | 18.58% | |
| GN1 | 19.00% | |
| GN3 | 19.35% | |
| JN3 | 19.44% | |
| GN2 | 19.74% | |
| GW1 | 20.94% | |
| DG4 | 21.52% | |
| GW2 | 24.88% | 어려움 |
| **JN2** | **34.94%** | **압도적 최악 (outlier)** |

**핵심 발견 — JN2 outlier**:
다른 그룹 평균 ~19%인데 JN2만 35%. **거의 2배**. 전남(JN) 그룹답게 방언 영향 추정.

정성 분석 예시 (JN2):
- "골다공증" → "**콜드라운측**" (방언/발음 변이)
- "눈이와" → "**돈이 와**" (모음 변이)

**시사점**: PPT의 "구음장애/80+" subgroup이 데이터셋에 명시 라벨로 없지만, **데이터 기반으로 자동 발견**됨 (= JN2 같은 어려운 그룹). 이게 E1 LoRA의 핵심 타깃.

## 4. 두 데이터셋 격차의 원인 — 5배 차이를 어떻게 설명하나

| 요인 | AI허브 (CER 4.25%) | VOTE400 (CER 20.38%) |
|---|---|---|
| **화자 수** | 5명 | 약 100명+ |
| **지역 다양성** | 3명 수도권 위주 | 5개 지역 (SE/DG/GW/GN/JN) |
| **연령** | 60~75세 | 65세 이상 광범위 |
| **데이터셋 의도** | 챗봇 학습용 (깨끗한 발화) | 노인 음성 인식 연구용 (다양성 의도적) |
| **라벨 형식 함정** | 큰 영향 (-2.60%p 정제 효과) | 거의 없음 (+0.70%p) |
| **방언** | 거의 없음 | JN2 등에서 두드러짐 |

**결론**: 5배 격차는 **데이터셋 설계의 차이**이지 측정 오류가 아니다. AI허브는 "쉬운 슬라이스", VOTE400은 "진짜 노인 인구의 대표 샘플".

## 5. PPT 원안 가설 재검토

### H1 — "LoRA 파인튜닝으로 노인 음성 CER 감소"

| 데이터셋 | 베이스라인 | 30% 상대개선 목표 | 검증 가능성 |
|---|---:|---:|---|
| AI허브 | 4.25% | 2.97% | ❌ 노이즈 수준 |
| **VOTE400 평균** | **20.38%** | **14.3%** | ✅ 가능 |
| **VOTE400 JN2** | **34.94%** | **24.5%** | ✅ 이상적 |

→ **H1 검증은 VOTE400에서 진행해야 함**. 특히 JN2 같은 어려운 그룹에서 큰 개선 폭 기대.

### H2 — "VAD 재튜닝으로 Deletion 감소"

→ **데이터로 명확히 반박**. PPT 발표에서는 "가설을 검증한 결과 반박되었고, 그 이유를 정성적으로 분석함으로써 모델 적응(LoRA) 방향이 정당화됨"으로 narrative 전환.

## 8. 발표 메시지 (다음 발표 후보)

오늘 결과로 만들 수 있는 narrative 3가지:

### "데이터셋 선택이 결과를 결정한다"
- AI허브 4.25% vs VOTE400 20.38% — 같은 "노인 음성" 라벨이지만 5배 차이
- 화자 다양성, 지역 방언, 라벨 형식 등이 결정 요인
- 메소드론적 시사: "어떤 노인 음성 데이터셋을 쓰느냐"가 연구 결론을 좌우

### "가설 검증의 정직함 — H2는 반박, H1은 살아남았다"
- 외부 VAD 가설(H2): 데이터로 반박 — 가설 폐기는 과학의 일부
- LoRA 가설(H1): VOTE400 격차로 검증 가능 상태 진입
- 사후합리화 금지, 결과 보고 가설 조정

### "VOTE400의 JN2 = LoRA의 진짜 검증 무대"
- 데이터셋에 "구음장애" 라벨이 없어도 데이터 기반으로 어려운 그룹 자동 발견
- JN2 35% → 24.5% (30% 상대 개선) 가 H1 검증의 명확한 목표
